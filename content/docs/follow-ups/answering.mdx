---
title: Answer a follow-up
description: For members, how to answer a follow-up in Slack, Microsoft Teams or Webex, and how to edit a response.
---

At the follow-up's time, Sup! sends you a message with three buttons:

![A Sup! message in Slack asking for updates, with Yes, Use previous response and Not working today buttons](/images/follow-ups/chat-message.png)

- **Yes**: answer today's questions.
- **Use previous response**: open the form already filled in with your last answers, then
  change what you need and submit.
- **Not working today**: tell Sup! you're off. Sup! replies *"I have marked you as not working
  today."* and posts that you're not working to the channel. This button only appears if the
  follow-up allows it.

The first time you're added to a follow-up, Sup! also introduces itself and tells you when the
follow-up runs and where your answers will be posted.

## Answering

<Tabs items={['Slack', 'Microsoft Teams', 'Webex']}>
<Tab value="Slack">

How you answer depends on the follow-up's interaction type.

**Dialog window**: **Yes** opens a form with the questions. If there's a blocker question, tick
**Do you have any blockers?** to answer it. If the follow-up tracks mood, pick an answer for
**How are you feeling today?** Then select **Submit**.

**Conversational**: after **Yes**, Sup! asks the questions one at a time and you reply by
typing. Optional questions have a **Skip** button, and **View previous answers** shows what you
said last time. For the blocker question, reply "no" or "none" if you have none.

You can also answer from a direct message to Sup!. Type
`response <follow-up-name> <YYYY-MM-DD>`, or type `help` to see how.

</Tab>
<Tab value="Microsoft Teams">

**Yes** opens a pop-up form with the questions. Leave the blocker question blank if you have no
blockers. Then select **Submit**.

</Tab>
<Tab value="Webex">

**Yes** turns the message into a form with the questions. Fill it in and select **Submit**.

</Tab>
</Tabs>

After you submit, Sup! sends the follow-up's thank-you message and posts your answers to the
channel, if the follow-up has one.

<Callout>
  If you start a conversational follow-up and don't finish, Sup! posts what you answered to the
  channel about two hours later, marked as an incomplete response.
</Callout>

## Reminders

If you haven't answered, you may get *"Your response for (follow-up name) is pending."* These
are the follow-up's automatic reminders. A manager can also remind you from the web app; that
message names who is reminding you and links to the response form.

## Edit a response

If the follow-up allows editing, the thank-you message has an **Edit response** button:

- **Slack, dialog window**: opens the form again, with an **On leave?** checkbox. Select
  **Update**.
- **Slack conversational, Microsoft Teams and Webex**: opens the response in the web app.

In a Slack conversational follow-up you can also edit or delete your own reply message.

On the follow-up's page in the web app, your own answers have an **Edit** link.

## Answer in the web app

On the follow-up's page, select **Add response** to answer for the selected date. If the
follow-up allows it, you can pick an earlier date to answer for a day you missed.

The page shows the same three buttons as the chat message. Select **Yes** to see the questions,
then **Submit response**. Turn on **Do you have any blockers?** to answer the blocker question.

![The Submit response page for Engineering standup on Oct 23, 2026, with two text questions, the blockers switch, an Options question and the mood question](/images/follow-ups/respond.png)

On Slack, the Sup! app's **Home** tab lists **Your follow-ups** with the same buttons.
